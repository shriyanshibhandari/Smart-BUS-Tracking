# 🚌 Smart Bus Tracking and Route Optimization System

## About the Project
The Smart Bus Tracking and Route Optimization System is a web-based application designed to help students track buses and find optimized routes. It provides bus tracking, estimated arrival times, and efficient route planning to improve transportation management.

## Features
- Student login and registration.
- Admin dashboard for bus management.
- Bus tracking and route information.
- Route optimization using graph algorithms.
- Estimated Time of Arrival (ETA).
- Traffic-based route analysis.
- User-friendly web interface.

## Technologies Used
- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Python (Flask)
- **Database:** Database Management System
- **Algorithms:** Dijkstra, BFS, DFS
- **Concepts:** Data Structures and Algorithms
